# AI-Based Posture & Fatigue Forecaster

A real-time AI-powered posture and fatigue monitoring system built using Python, OpenCV, and MediaPipe.

## Features
- Real-time webcam posture tracking
- Neck bending detection
- Shoulder alignment analysis
- AI posture classification
- Voice posture alerts
- Fatigue monitoring

## Tech Stack
- Python
- OpenCV
- MediaPipe
- NumPy
- pyttsx3

## Future Scope
- Eye fatigue detection
- Meeting analytics
- Desktop notifications
- Background monitoring
